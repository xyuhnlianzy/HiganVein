Changelog & Technical Milestones

Documenting core fixes, package changes, and installer architecture updates.

Release 2026.09.23 (Stable v1.0 — Post-Audit & Battle-Tested) Latest
  • Terminal & Shell Upgrade: Replaced Kitty with ptyxis (GTK4/Adwaita terminal with flawless native clipboard support) and set default interactive shell to fish with integrated fastfetch sigil greeting and autosuggestions.
  • Full Bootloader Tri-Engine Synchronization:
    • Limine UEFI: Automated kernel and initramfs injection into ESP FAT32 partition (boot():), NVRAM registration via efibootmgr, transparent terminal background, and removed duplicate branding overlay over Frieren artwork.
    • systemd-boot: Dual-path configuration mirroring (/boot/loader and /boot/efi/loader) with automated CPU microcode entries and default fallback binaries.
    • GRUB (BIOS & UEFI): Set GRUB_DISTRIBUTOR="HiganveinOS" to eliminate upstream Arch Linux text from menu headers, with verified Btrfs subvolume (rootflags=subvol=@) commandline passthrough.
  • Post-Install Network & Security Automation:
    • Automated enabling of NetworkManager.service and systemd-resolved on installed target disks with fallback DNS (1.1.1.1).
    • Automated pacman-key --init and --populate archlinux cachyos execution to ensure zero GPG trust errors on first boot.
    • Cleaned up live environment guard scripts (/usr/local/bin/pacman) upon installation completion.
  • Desktop & Branding Polish: Replaced upstream fallback icons in KDE System Info with official SVG H.V Monogram, corrected external documentation links to prevent 404s, and hid standalone Rofi launchers from KDE Kickoff to prevent 'Lost & Found' menu clutter.
  • Verified Minimum Specs: Officially certified for 2 Cores CPU, 1 GB RAM (single lightweight task, no bundles), and 30 GB storage. Tested under full CPU stress-ng workloads.

Release 2026.09.20 (Public Beta) Previous
