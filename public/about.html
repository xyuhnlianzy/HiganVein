About the HiganveinOS Project

HiganveinOS is an independent open-source Linux distribution project led by Yu Dyan.

Design Philosophy

The project was conceived around computing sovereignty: rejecting intrusive telemetry, removing heavy runtime dependencies, and optimizing low-spec hardware responsiveness. We maintain two release tracks:

  • Sovereign Void Linux: Pure runit service supervision, Linux 6.6 LTS, custom micro-initramfs, and an idle memory footprint of ~180 MiB RAM.
  • Arch Linux Flagship: CachyOS BORE scheduler, Higanvein Unified Shell (GTK3/C), and complete development and gaming toolchains.

Upstream Acknowledgments

HiganveinOS builds directly upon the work of several foundational open-source efforts:

  • Void Linux — Independent base, XBPS package management, and runit supervisor design.
  • Arch Linux — Rolling distribution ecosystem, pacman toolchain, and archiso engine.
  • CachyOS — Linux kernel performance patches and the BORE (Burst-Oriented Response Enhancer) CPU scheduler.
  • hein — Native Rust wrapper around XBPS providing clean terminal interface and package caching.
  • higan-installer — Native compiled Rust disk partitioner and EFI/BIOS bootloader configurator.
  • Labwc & Ptyxis — Lightweight Wayland stacking compositor and container-ready terminal emulator.
  • WebKitGTK — The rendering foundation powering our low-RAM Lycoris web browser.
