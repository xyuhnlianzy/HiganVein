Changelog & Technical Milestones

Documenting core fixes, package changes, and installer architecture updates.

Release 2026.09.21 (Public Beta v5.0) Latest
  • Higan-Installer v5.0: Full UI overhaul inspired by Calamares, Anaconda, and Pop!_OS research. Features color-coded partition bars, clean zinc-red dark mode, and zero marketing fluff.
  • Multi-Bootloader Choice: Added interactive bootloader selection supporting Limine (modern/fast default), GRUB (universal dual-boot with os-prober), and systemd-boot (minimal native UEFI).
  • Default Live & Installed Wallpaper: Apocalyptic red spider lily landscape ("彼岸 HIGAN / THE VOID REMAINS") forced as native default across KDE Plasma and SDDM.
  • Partition Manager Tooling: Added KDE Partition Manager (kpmcore + partitionmanager) with direct launcher for advanced manual disk partitioning.
  • Btrfs Subvolumes by Default: Automated subvolume topology (@, @home, @snapshots) with transparent ZSTD compression.
  • New ASCII Sigil: Geometric orb-pillar fastfetch branding logo replacing legacy generic artwork.
Release 2026.09.20 (Public Beta) Previous
  • Higan-Installer v4.0 Pro: Rewritten native PyQt6 wizard with interactive Dual-Boot storage slider, dynamic drive model queries, and live system safety filters.
  • Multi-Boot Integration: Added os-prober and universal GRUB configuration supporting automated Windows, Linux, and BSD detection.
  • Kernel & Memory: Upgraded to CachyOS BORE scheduler with earlyoom daemon protection and zstd ZRAM (2× RAM size).
  • Windows Compatibility Stack: Integrated Wine runtime with 32-bit and 64-bit Vulkan drivers for out-of-the-box .exe execution.
  • Hardware Firmware: Added Broadcom wireless DKMS, SOF audio firmware, and power-profiles-daemon for laptop battery management.
