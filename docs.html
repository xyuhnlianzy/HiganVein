Installation & Guide

Documentation

Documentation is being prepared alongside testing. HiganveinOS is not stable yet.

1

Flashing the ISO to a Flash Drive

Public ISO downloads are not available yet. When stable release is announced, use Ventoy (recommended for multi-boot), Rufus (DD mode), or dd in Linux.

sudo dd if=higanveinos-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
2

Booting into Live Environment

Plug your USB drive into your target PC/Laptop (supports both Legacy BIOS and UEFI). Enter your BIOS/Boot Menu during startup and select the USB drive. You will be greeted by our custom bootloader with the HiganveinOS live entry.

3

Installing via Calamares GUI

Once stable release is announced, boot into the KDE Plasma live desktop and start Calamares from HiganveinOS Welcome. It will guide partitioning, user account setup, password setup, and installation.
