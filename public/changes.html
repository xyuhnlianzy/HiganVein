Changelog & Technical Milestones

Documenting core fixes, package changes, and installer architecture updates.

2026.09.22 Release 2026.09.22 (Stable v1.0)
  • 11-layer deep audit: fixed /etc/group missing audio/video/storage/input groups
  • Fixed sudoers 0644→0440 — sudo was silently ignoring wheel rule
  • Added KWin compositor config, KScreenLocker (off), KSplash (disabled) to skel
  • Added mesa base package (was only lib32-mesa)
  • Fixed installer Wayland sudo display socket passthrough
  • Fixed installer: clean live user/autostart artifacts from installed system
  • Fixed sudoers file permissions on installed user account
  • Added --help flag to higan-bundle
  • ISO uploaded to Hugging Face — 2.99 GB
Release 2026.09.21 (Public Beta v5.0 — Release Candidate 1) Latest
  • Custom Anime Bootloader Art: Unified split-screen bootloader theme across GRUB, Limine, and Syslinux featuring Frieren in a red spider lily field with dedicated left-hand menu framing.
  • Higan-Installer v5.0: Full UI overhaul inspired by Calamares, Anaconda, and Pop!_OS research. Features color-coded partition visualization bars, clean zinc-red dark mode, and zero marketing fluff.
  • Interactive Bootloader Selection: Choose between Limine (modern/fast default), GRUB (universal dual-boot with automated os-prober), and systemd-boot (minimal native UEFI) during installation.
  • Modular Profile Architecture (higan-bundle): Post-install profile management tool to install tailored software suites:
    • Gaming Suite: Steam, Heroic Games Launcher, ProtonUp-Qt (GE-Proton), GameMode, MangoHud, xpadneo Xbox Bluetooth driver, and memory tweak (vm.max_map_count=1048576).
    • Developer Toolchain: VSCodium, Neovim, full compiler stack (GCC, Clang, Rustup, Go, Python, Node.js), Docker engine with automated non-root group assignment, and modern Rust CLI tools.
    • Ricing Enthusiast: Hyprland Wayland compositor, Waybar, Rofi-wayland, Waypaper GUI wallpaper picker, Mako notifications, Grim/Slurp screenshot suite, Hyprlock, Cava, and Starship prompt.
  • Interactive Web Configurator: Live bundle generator at /bundles with quick reference terminal cheatsheets.
  • Desktop Aesthetic Overhaul: KDE Plasma Breeze Dark with Spider Lily Crimson Red accent (#ef4444), custom H.V Monogram vector launcher icon, HiganVoid Konsole theme, and automatic fastfetch sigil display on terminal launch.
  • UEFI Root Label Fix: Resolved uninitialized variable in efiboot GRUB configuration to prevent initramfs boot timeouts on certain modern UEFI motherboards.
  • Btrfs Subvolumes by Default: Automated subvolume layout (@, @home, @snapshots) with transparent ZSTD filesystem compression.
Release 2026.09.20 (Public Beta) Previous
  • Higan-Installer v4.0 Pro: Rewritten native PyQt6 wizard with interactive Dual-Boot storage slider, dynamic drive model queries, and live system safety filters.
  • Multi-Boot Integration: Added os-prober and universal GRUB configuration supporting automated Windows, Linux, and BSD detection.
  • Kernel & Memory: Upgraded to CachyOS BORE scheduler with earlyoom daemon protection and zstd ZRAM (2× RAM size).
  • Windows Compatibility Stack: Integrated Wine runtime with 32-bit and 64-bit Vulkan drivers for out-of-the-box .exe execution.
  • Hardware Firmware: Added Broadcom wireless DKMS, SOF audio firmware, and power-profiles-daemon for laptop battery management.
