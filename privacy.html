Privacy Policy

Effective Date: September 24, 2026 · Zero Data Collection Architecture

1. Core Privacy Principle: Zero Telemetry

HiganveinOS is an independent, non-profit open-source operating system distribution maintained by developers under the public attribution "D-P" and community contributors. We adhere strictly to the principle of Zero Data Collection.

We do not track, log, profile, sell, or collect personal data, hardware telemetry, IP addresses, usage patterns, or operating system diagnostic metrics from any visitor to this website or user of the HiganveinOS operating system.

2. Website & Server Infrastructure

This website (higanvein.pages.dev) is statically hosted on Cloudflare Pages.

  • No Tracking Scripts: We do not use Google Analytics, Meta Pixel, tracking beacons, or profiling session recorders.
  • No Third-Party Advertising: There are zero advertising trackers or monetization SDKs on this website.
  • Server Logs: Cloudflare may process ephemeral HTTP request logs (IP address, user agent) strictly for DDoS mitigation and infrastructure security in accordance with their standard privacy practices. We do not store or inspect these logs.

3. Cookies & Local Storage

This website operates on a Zero-Cookie Policy. We do not place tracking cookies, advertising cookies, or cross-site fingerprinting identifiers on your machine.

Interactive interface components (such as bundle command generators) run purely in client-side memory and do not persist trackers to your disk.

4. Operating System Privacy

The HiganveinOS operating system ISO image does not ship with phone-home services, diagnostic analytics daemons, or vendor telemetry agents.

  • Package management requests connect directly to official community mirror repositories (Arch Linux, CachyOS, and SourceForge).
  • Network traffic occurs strictly when initiated by user applications.

5. Project Governance & Contact

HiganveinOS is developed collaboratively as open-source software under GitHub repository: github.com/xyuhnlianzy/HiganVein.

For technical inquiries, audit reports, or privacy notices, reach out via our community infrastructure on Discord (discord.gg/HQANxjyfKx) or submit a GitHub issue.
