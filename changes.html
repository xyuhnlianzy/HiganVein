Changelog & Technical Milestones

Documenting core fixes, package changes, and installer architecture updates.

Release 2026.09.24 (Global Mirrors & AI Stack) Latest
  • Global Mirror Migration (SourceForge): Established official project mirror at SourceForge with high-speed global CDN routing, automatic resume capability, and direct download links across all editions.
  • Cybersecurity Arsenal & BlackArch Integration: Upgraded higan-bundle --cyber with offensive security tools from Kali, ParrotOS, and BlackArch (Nmap, Wireshark, Metasploit, Ghidra, Bettercap, Proxychains). Added automated BlackArch repository integration via higan-bundle --blackarch to access 2,800+ specialized packages.
  • Agentic AI Infrastructure Stack: Introduced higan-bundle --ai-agent enabling out-of-the-box local and cloud AI agent workflows. Packages Ollama daemon, 9Router multi-provider rate-limiting gateway, Hermes autonomous agent environment, and system health utility higan-ai-status.
  • Core CLI v6 Integrity Fixes: Resolved GPG time-warp clock issues via automated systemd-timesyncd & hwclock target synchronization, initialized archlinux-keyring, and cleaned bootloader menu branding to HiganveinOS Core with ~316 MiB idle memory footprint.
2026.09.23 Release 2026.09.23 (Stable v1.0 — Post-Audit)
  • Phase 2 Modular Init Architecture (Systemd / OpenRC / Runit) preview
  • Ecosystem & Snapshot Rollback with Paru, Flatpak, and Btrfs-Assistant / Snapper
  • Laptop Hardware Optimization (Touchpad, Fn-keys, brightnessctl, power profiles)
  • ZRAM swap multiplier tuned to 2.5× physical RAM
  • Full Bootloader Tri-Engine Synchronization (Limine UEFI, systemd-boot, GRUB)
2026.09.22 Release 2026.09.22 (Pre-Audit Candidate)
  • 11-layer deep audit: fixed /etc/group missing audio/video/storage/input groups
  • Fixed sudoers 0644→0440 — sudo was silently ignoring wheel rule
  • Added KWin compositor config, KScreenLocker (off), KSplash (disabled) to skel
  • Added mesa base package (was only lib32-mesa)
  • Fixed installer Wayland sudo display socket passthrough
  • Fixed installer: clean live user/autostart artifacts from installed system
  • Fixed sudoers file permissions on installed user account
  • Added --help flag to higan-bundle
2026.09.21 Release 2026.09.21 (Public Beta v5.0 — Release Candidate 1)
  • Custom Anime Bootloader Art across GRUB, Limine, Syslinux featuring Frieren.
  • Higan-Installer v5.0 with real-time partition visualizer bars and dual-boot allocation.
  • Modular profile installer (higan-bundle) for Gamer, Developer, and Ricing stacks.
  • Btrfs subvolume layout (@, @home, @snapshots) with transparent ZSTD compression.
Release 2026.09.20 (Public Beta) Previous
  • Higan-Installer v4.0 Pro: Rewritten native PyQt6 wizard with interactive Dual-Boot storage slider, dynamic drive model queries, and live system safety filters.
  • Multi-Boot Integration: Added os-prober and universal GRUB configuration supporting automated Windows, Linux, and BSD detection.
  • Kernel & Memory: Upgraded to CachyOS BORE scheduler with earlyoom daemon protection and zstd ZRAM (2× RAM size).
  • Windows Compatibility Stack: Integrated Wine runtime with 32-bit and 64-bit Vulkan drivers for out-of-the-box .exe execution.
  • Hardware Firmware: Added Broadcom wireless DKMS, SOF audio firmware, and power-profiles-daemon for laptop battery management.
