System Architecture & Specifications

HiganveinOS is built strictly on verified Linux technologies, rejecting telemetry, bloated runtimes, and unnecessary background daemons.

Core Subsystems

runit Process Supervisor

On the Sovereign Void edition, stage scripts (00-pseudofs.sh, 03-filesystems.sh, 04-swap.sh) provide deterministic early userspace initialization without systemd dependencies. Service directories under /etc/sv/ link directly into /var/service/.

Native Rust Disk Installer

Our installer (higan-installer) is a static 419 KB Rust binary requiring under 2 MB RAM during live execution. Handles NVMe (nvme0n1pX), SATA, and VirtIO partition schemes, chroot package installation, and automated hybrid BIOS/UEFI boot configuration.

Dual-Mode Hybrid Bootloader

A single unified ISO supports both Wayland graphical desktop and minimal terminal console boots. Boot flags (higan.mode=gui vs higan.mode=cli) dictate early userland service startup without needing multiple images.

CachyOS BORE Kernel & 6.6 LTS

Arch Flagship editions leverage the Burst-Oriented Response Enhancer (BORE) scheduler for minimal desktop latency under thread contention. Sovereign Void editions pin Linux 6.6 LTS for stability and broad hardware reliability.

Integrated GPU Microcode

Firmware microcode blobs for AMDGPU, Intel Iris/Arc, and NVIDIA (proprietary and open modules) are integrated into userspace and initramfs to ensure video acceleration works on initial boot.

Cross-Distro Bundle Engine

higan-bundle automatically detects the active base distribution (Void Linux via xbps / Arch Linux via pacman) to provision Gamer, Dev, Ricer, Cyber, or AI Agent stacks with proper service symlinks.
