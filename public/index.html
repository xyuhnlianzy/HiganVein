The Higanvein (Linux) distribution

HiganveinOS is an independent, sovereign operating system designed for low-latency desktop responsiveness and complete privacy. Built on a non-systemd Void Linux core with pure runit service supervision, custom micro-initramfs, and native C/Rust userland utilities.

Software packages are managed via XBPS and our native hein Rust wrapper. Memory footprint is strictly constrained to <200 MiB idle RAM, with zero telemetry daemons and automated ZRAM compressed swap.

Sovereign runit Core

We use runit as the default init system and process supervisor on the Sovereign edition. Fast, deterministic startup stages without complex binary logging daemons.

Native Toolchains in Rust & C

Core system utilities avoid heavy Python or Electron dependencies: higan-installer (Rust), hein package wrapper (Rust), and higan-lock/higan-shot (Wayland C).

Zero Telemetry Guarantee

All corporate telemetry endpoints, crash reporters, and analytics domains are sinkholed directly to 0.0.0.0 in /etc/hosts. No telemetry daemons are installed or run in background.

Low-Latency Kernel Tuning

Offers verified Linux 6.6 LTS on Sovereign Void and CachyOS BORE (Burst-Oriented Response Enhancer) on the Arch edition, reducing input latency during heavy compilation workloads.

Hardware Memory Defense

Integrated ZRAM swap with zstd compression enabled during early userspace boot (04-swap.sh) paired with tuned earlyoom rules to prevent system freezes on low-spec hardware.

Lycoris Web Platform

Lightweight default browser compiled from native C, C++, Rust, and Zig over WebKitGTK. Consumes ~45-60 MB RAM at idle with built-in ad-blocking and native search routing.
