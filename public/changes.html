Changelog & Status

Changes, Improvements & Fixes

Tracking all engineering milestones, core fixes, and custom implementations for HiganveinOS.

Alpha Build v1.0-2026.09.19 Latest Release

Native Python Installer (`higan-installer`)

Menggantikan Calamares yang sering mengalami konflik dependensi C++ / Boost version mismatch. Installer baru ditulis kustom dengan PyQt6, mendeteksi disk lokal, mempartisi GPT/ESP, memformat partisi, rsync root dengan aman (mengecualikan virtual filesystem /dev, /proc, /sys), serta otomatis menginstal GRUB ke UEFI dan mendaftarkan user baru.

Graphical GRUB Bootloader & Legacy BIOS Rebranding

Menghilangkan seluruh jejak identitas "Arch Linux" pada menu boot. Menambahkan custom graphical GRUB theme dengan background artwork Higan Void & Red Spider Lily, lengkap dengan startup banner eksklusif HiganveinOS Core v1.0.

Performance & Stability Improvements

  • Integrasi otomatis ZRAM swap sebesar 2× RAM fisik dengan algoritma kompresi `zstd`.
  • Mengaktifkan NetworkManager secara default pada systemd target live session.
  • KDE Plasma sebagai satu-satunya default desktop environment yang di-rice dengan wallpaper eksklusif Higan Void.
