Kernel & I/O

CachyOS BORE Kernel

Burst-Oriented Response Enhancer scheduler prioritizing interactive desktop tasks with reduced frame jitter.

Memory Control

ZRAM 2.5× & EarlyOOM

Compressed RAM swap using zstd (2.5× detected physical RAM) paired with earlyoom daemon to prevent system locks during high memory workloads.

Storage & Rollback

Btrfs & Snapper GUI

Subvolumes (@, @home, @snapshots) with native ZSTD compression and 1-click Btrfs Assistant snapshot restore points.

Phase 2 Architecture

Modular Init System

Freedom of choice: install with standard Systemd, ultra-lean OpenRC, or minimal Runit with automated kernel handoffs.

Hardware Tri-Stack

Intel · AMD · NVIDIA

Out-of-the-box Vulkan & media acceleration for Intel/AMD, plus automated Wayland DRM setup and official NVIDIA suite.

App Ecosystem

Paru AUR & Flatpak

Built-in Rust AUR helper, Flathub software center, Ptyxis terminal, and modular higan-bundle CLI stacks.

Developer Note & Issue Reporting

HiganveinOS is developed independently by D-P. We prioritize verifiable system stability over superficial feature additions. If you experience partition issues, driver regressions, or bootloader anomalies, open a GitHub Issue with your hardware configuration, system logs, and exact steps to reproduce.
