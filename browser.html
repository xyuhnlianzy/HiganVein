Tri-Engine Core

Three Languages. Zero Compromise.

Each layer is written in the exact right tool for the job.

01 · Rust

Memory-Safe Engine

Powers windowing, IPC messaging, and custom protocol filtering. Intercepts outgoing requests to strip tracking tokens and telemetry headers before they touch the wire.

wry · tao · zero panic
02 · C++

Aggressive RAM Trimmer

A native hook executing malloc_trim(0) upon every page load. Forces glibc to surrender allocated heap pages back to the Linux kernel immediately.

libhigan_trim.so · -O3 PIC
03 · Python

Clean Query Orchestrator

Handles command-line invocation, profile routing, and URL query sanitization. Automatically injects udm=14 into Google searches to enforce pure web mode.
