Stable Release v1.0 (x86_64)

High-performance Arch Linux, refined for everyday development and gaming.

HiganveinOS pairs the CachyOS BORE kernel with KDE Plasma, proactive memory management, and a custom multi-boot installer that works alongside your existing operating systems.

Download ISO (~2.8 GB) GitHub Repository
Kernel & I/O

CachyOS BORE Kernel

Burst-Oriented Response Enhancer scheduler prioritizing interactive desktop tasks with reduced frame jitter.

Memory Control

ZRAM 2× & EarlyOOM

Compressed RAM swap using zstd paired with earlyoom daemon to prevent system locks during high memory workloads.

Storage Layout

Btrfs Subvolumes

Automated subvolume topology (@, @home, @snapshots) with native transparent ZSTD filesystem compression.

Modular Profiles

Higan-Bundle CLI

Zero-bloat ISO. Choose and install Gamer, Developer, or Ricing software stacks with one terminal command.

Developer Note & Issue Reporting

HiganveinOS is developed independently by D-P. We prioritize verifiable system stability over superficial feature additions. If you experience partition issues, driver regressions, or bootloader anomalies, open a GitHub Issue with your hardware configuration, system logs, and exact steps to reproduce.
