HiganveinOS Handbook

Essential instructions for preparing live media, deploying to NVMe/SATA targets, and managing runit system daemons.

1. Preparing Installation Media

Download the official unified ISO from our SourceForge mirror. Write the image directly to raw block storage using dd: 

sudo dd if=higanveinos-sovereign-2026.10.09-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync

2. Booting the Live System

Boot from the USB drive via your UEFI/BIOS menu. The unified bootloader menu provides two boot modes:

  • GUI Mode (Default): Starts the lightweight Labwc Wayland session, launching HiganTerm and audio services automatically.
  • CLI Mode: Boots into pure VT1 console, suitable for server deployments and headless machines.

3. Disk Installation (higan-installer)

Open HiganTerm or login as root / higan on TTY1, then invoke the static Rust installer: 

sudo higan-installer

The installer handles automatic disk partitioning for NVMe (nvme0n1pX) and SATA drives, formats the 512 MB EFI System Partition (ESP), copies rootfs files, generates hybrid BIOS/UEFI bootloaders, and sets system credentials safely.

4. Service Supervision with runit

On the Sovereign Void edition, services are managed by creating or removing symlinks inside /var/service/: 

# Enable a daemon:
sudo ln -s /etc/sv/sshd /var/service/

# Check status or restart:
sudo sv status sshd
sudo sv restart sshd

# Disable a daemon:
sudo rm /var/service/sshd

5. Package Management

Use the native hein Rust tool or standard xbps commands to update your system: 

# Synchronize and update repository packages:
sudo hein update
sudo xbps-install -Su

# Install software:
sudo hein install git gcc neovim
