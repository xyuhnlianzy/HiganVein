Installation Guide

Step-by-step instructions for flashing and installing HiganveinOS.

Step 1

Write ISO to USB Media

Flash the downloaded ISO image using Ventoy, Rufus (in DD image mode), or directly via Linux terminal:

sudo dd if=higanveinos-2026.09.22-x86_64.iso of=/dev/sdX bs=4M status=progress oflag=sync
Step 2

Booting Live Environment

Insert the USB drive into your target machine. Select the drive in your BIOS/UEFI boot selector. Both standard UEFI and Legacy BIOS hardware platforms are supported out of the box.

Step 3

Running Higan-Installer

Launch HiganveinOS Setup from the desktop. Follow the 8-step wizard:

  • Partitioning: Pick Erase Disk, Dual-Boot (with storage slider), or Manual Partitioning via KDE Partition Manager.
  • Bootloader: Choose between Limine (fast modern EFI), GRUB (universal dual-boot with Windows auto-detect), or systemd-boot.
  • Filesystem: Select Btrfs (recommended, auto-creates @, @home, @snapshots subvolumes with ZSTD compression) or Ext4.
Step 4

Post-Installation: Customize via Bundles

After rebooting into your fresh install, tailor your environment using the built-in profile manager:

# Interactive menu:

sudo higan-bundle

# Or install specific stacks directly:

sudo higan-bundle --dev --gamer

Visit our interactive Bundles Configurator to generate your custom installation command.
