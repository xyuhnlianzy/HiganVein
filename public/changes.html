News & Release History

Documenting architectural decisions, security advisories, kernel audits, and package repository updates.

October 24, 2026

Release 2026.10.24: Arch SystemD Consolidation, Limine Tech-Noir, and Windows Engine

Major architectural pivot focusing engineering resources directly on our Arch Linux SystemD Flagship tier for superior hardware acceleration, gaming, and daily driver reliability:

  • Kernel Optimization (linux-cachyos-lts): Transitioned to Linux 6.18 LTS with CachyOS BORE scheduler, shaving idle RAM to ~220–250 MiB while preserving top-tier desktop responsiveness.
  • Limine Modern Bootloader (Default): First-class integration of Limine with native monitor resolution, custom Spider Lily Tech-Noir theme, and automatic zero-overhead chainload detection for Windows Boot Manager and macOS OpenCore.
  • Compact Native Windows Engine (higan-wine): Out-of-the-box double-click execution for .exe and .msi binaries with subpixel font smoothing, disabled Gecko/Mono popups, GameMode integration, and desktop task killer (higan-kill-wine).
  • Bulletproof Dual-Engine Installer: Upgraded higan-installer-launcher with automated VM software rendering fallback (LIBGL_ALWAYS_SOFTWARE=1) and high-speed Rust CLI engine (higan-installer-cli) for reliable Multi-Boot alongside Windows/macOS.
  • ISO Footprint Reduction: Trimmed duplicate browsers and bloated packages, cutting ISO size down from 2.8 GB to ~1.3 GB.
  • Void Runit Track: Preserved under sovereign-builder/ in status On Hold for dedicated research.
October 17, 2026

Release 2026.10: Native Toolchain Consolidation & Dual ISO Harmonization

This release concludes our migration away from heavy script interpreters on live install media, solidifying the two primary distribution tiers:

  • Native Rust Installer (higan-installer): Completely replaces legacy Python disk partitioning routines with a standalone 419 KB static binary consuming less than 2 MB resident memory.
  • Sovereign Void Linux Core: Non-systemd release running tickless 1000Hz preemption kernel (6.6.158 LTS), custom micro-initramfs, and pure runit stage execution with an idle memory usage of ~180 MiB.
  • Unified Hybrid Boot Architecture: Discontinued separate minimal CLI ISOs. Each image now contains full Wayland GUI and console targets, controlled via bootloader command-line parameters (higan.mode=gui / higan.mode=cli).
  • Hardware Microcode Blobs: Pre-loaded vendor firmware for AMDGPU, Intel Arc/Iris, and NVIDIA cards into the Void rootfs to eliminate black-screen boots.
  • Universal Bundle Provisioner: higan-bundle updated to automatically detect host package and init facilities (Void/XBPS vs Arch/Pacman).
October 14, 2026

Lycoris Browser: Quad-Core Native Architecture

Launched our default sovereign web platform built on WebKitGTK 4.1 with a hybrid compiled architecture: C window shell, C++ heap compaction (malloc_trim), Rust tracker sinkholing, and Zig omnibox query sanitizer. Delivers ~45–60 MB idle RAM consumption and native hardware video acceleration.

September 24, 2026

Release 2026.09.24: High-Speed Mirror Infrastructure & ZRAM Auto-Tuning

Migrated public downloads to global SourceForge high-speed CDN mirrors. Tuned early userspace ZRAM swap multiplier to 2.5× physical RAM using zstd compression, coupled with customized earlyoom kill rules to prevent desktop stalls during heavy compilation or large memory allocations.
