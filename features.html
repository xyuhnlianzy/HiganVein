System Specifications & Features

Detailed components and technical choices in current HiganveinOS builds.

CachyOS Linux Kernel

Custom x86-64-v3 optimized kernel with BORE (Burst-Oriented Response Enhancer) scheduler. Prioritizes desktop interactivity, input latency, and consistent frame rates under heavy background compilations or gaming workloads.

Higan-Installer v5.0 (PyQt6)

Custom 8-step wizard inspired by Calamares and Anaconda. Features interactive Dual-Boot storage allocation slider, real-time color-coded partition visualization bars, and direct KDE Partition Manager integration.

Multi-Bootloader Architecture

First-class support for Limine (modern, minimal, ultra-fast), GRUB (universal dual-boot with automated os-prober for Windows/other distros), and systemd-boot (native UEFI).

Software Ecosystem & AUR

Pre-installed paru (Rust-based ultra-fast AUR helper) for instant access to thousands of community packages, alongside Flatpak with pre-configured Flathub repository integration in KDE Discover.

Btrfs Subvolumes & Snapshot Rollback

Automated layout partitioning into @ (root), @home (user data), and @snapshots with transparent ZSTD filesystem compression. Features btrfs-assistant GUI and snapper timeline automation for 1-click system restore points.

Modular Profile Manager (higan-bundle)

Keep your core ISO small (~2.8 GB). Easily install specialized software stacks on demand: Gaming Suite (Steam, Heroic, ProtonUp-Qt), Developer Suite (VSCodium, compilers, Docker), or Ricing (Hyprland Wayland suite).

Custom Split-Screen Bootloader Theme

Anime-inspired artwork boot interface across GRUB, Limine, and Syslinux featuring Frieren in a red spider lily landscape with high-contrast left-framed navigation menus.

Memory & Swap Configuration

Compressed RAM swap via zstd (2.5× physical RAM) configured via systemd-zram-generator. Paired with earlyoom daemon to prevent system lockups when physical memory reaches 90% threshold.

Windows Compatibility Layer

Pre-installed Wine runtime with full 32-bit and 64-bit Vulkan graphics libraries (Mesa, Intel, AMD). MIME associations allow direct double-click execution of .exe and .msi binaries from Dolphin.

Full GPU Tri-Stack (Intel, AMD, NVIDIA)

Out-of-the-box hardware acceleration for all Big 3 GPU vendors. Intel HD/Iris via intel-media-driver, AMD Radeon via Mesa RADV (64 & 32-bit), and NVIDIA Wayland integration via egl-wayland with automated installer DRM modesetting. Dedicated proprietary suite available via sudo higan-bundle --nvidia.

Laptop Optimization Suite

Tuned for portable hardware: out-of-the-box Touchpad Tap-to-Click & natural scrolling, power-profiles-daemon with battery-saver profiles, ACPI lid-close event handling, native Fn brightness hotkey control via brightnessctl, and Bluetooth auto-enable.

Terminal & Default Shell

Ships with Ptyxis as the default container-aware terminal emulator for reliable clipboard integration, paired with Fish interactive shell featuring out-of-the-box syntax highlighting, autosuggestions, and fastfetch system telemetry.

Field-Verified Hardware Footprint

Stress-tested under synthetic CPU & memory loads. Officially certifies a bare minimum of 2 CPU Cores, 1 GB RAM (single lightweight workload, no bundles), and 30 GB disk space with active ZRAM compression.

12-Layer Continuous Deep Audit

Every HiganveinOS ISO image release undergoes an automated 12-layer continuous deep diagnostic audit before distribution. This rigorous pipeline guarantees zero critical regressions, flawless dependency resolution, and verified permission boundaries from hardware firmware to user space.
