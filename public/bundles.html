Quick Reference Guide

You can install any profile individually or combine multiple stacks using simple terminal commands:

# Gaming only:

sudo higan-bundle --gamer

# Developer & Compilers only:

sudo higan-bundle --dev

# Ricing (Hyprland) only:

sudo higan-bundle --ricer

# Gaming + Developer combined:

sudo higan-bundle --gamer --dev

# Interactive Mode (shows terminal menu with choices 1-5):

sudo higan-bundle
