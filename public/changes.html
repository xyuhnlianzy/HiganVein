Changelog & Technical Milestones

Documenting core fixes, package changes, and installer architecture updates.

Release 2026.10.16 (Sovereign Dual-Edition & Native Rust Overhaul) Latest
  • Sovereign Void Linux Base & Kernel 6.6 LTS: Released non-systemd sovereign edition running pure Runit stages, tickless 1000Hz preemption kernel (6.6.158 LTS), custom micro-initramfs (3.4 MB), and an idle RAM footprint of ~180 MiB.
  • Unified Dual-Mode Bootloader (One ISO per Edition): Both Arch and Void variants now pack GUI Desktop (Wayland / Labwc / Higanvein-Shell) and CLI Pure Console modes into a single unified hybrid ISO, selectable directly at the GRUB / Syslinux bootloader menu.
  • Native Rust Installer (higan-installer): Rebuilt core disk installer in pure native Rust (419 KB static binary, <2 MB RAM), replacing legacy Python interpreters and saving memory on potato hardware. Added automatic NVMe, eMMC, SATA SSD, and VirtIO detection with hybrid BIOS/UEFI GRUB generation.
  • Full Hardware GPU & Acceleration Stack: Injected signed firmware microcode blobs for AMD Radeon RX (RDNA 1–4, Polaris, Vega), NVIDIA GeForce GTX/RTX (Maxwell to Blackwell), and Intel Arc/Xe (GuC/HuC). Full Vulkan userspace drivers (mesa-vulkan-nouveau/NVK, radv, anv) and VA-API hardware acceleration out of the box.
  • HiganTerm (Ptyxis Rebranding) & Wayland Desktop Stack: Adopted GNOME Ptyxis rebranded as HiganTerm with custom Spider Lily crimson palette (#0b070f, #e11d48). Integrated higan-lock (ext-session-lock-v1), higan-shot screenshot suite (grim + slurp), Thunar file manager, brightnessctl backlight, and PipeWire audio Fn-key bindings.
  • Universal higan-bundle Architecture: Refactored higan-bundle to run seamlessly across both Void Linux (hein / xbps + runit) and Arch Linux (pacman + systemd) for Gamer, Dev, Ricer, Cyber, and Agentic AI stacks.
