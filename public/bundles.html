Modular Profile Bundles (higan-bundle)

HiganveinOS keeps ISO images lean by default. Additional workflows are installed on-demand through our universal multi-distro provisioner.

Gaming Suite --gamer

Configures a low-latency gaming environment with Wine, Proton, GameMode, and controller drivers.

  • Client & Launchers Steam, Heroic Games, Lutris
  • Compatibility ProtonUp-Qt, Wine-GE
  • Kernel Tweaks GameMode, MangoHud
  • Peripherals xpadneo (Xbox wireless)
sudo higan-bundle --gamer

Developer Toolchains --dev

Complete compiler suite, containers, modern terminal utilities, and developer editors.

  • Compilers GCC, Clang, Rustup, Go
  • Runtimes Python 3.12, Node.js (LTS)
  • Editors VSCodium, Neovim
  • Virtualization Docker & containerd
sudo higan-bundle --dev

Wayland Tiling & Ricing --ricer

Custom Wayland desktop stack with dynamic tiling, status bar, and Spider Lily color palette.

  • Window Managers Hyprland / Labwc
  • Panels & Docks Waybar, Serpantinum
  • Lock & Shot higan-lock, higan-shot
  • Aesthetics Starship, Cava, Waypaper
sudo higan-bundle --ricer

Cybersecurity & Pen-Testing --cyber

Network analysis, packet inspection, wireless auditing, and reverse engineering tools.

  • Recon & Mapping Nmap, Masscan, Amass
  • Traffic Analysis Wireshark, tcpdump, TShark
  • Web & Proxies Burp Suite, OWASP ZAP, sqlmap
  • Wireless Aircrack-ng, Kismet
sudo higan-bundle --cyber

Universal Execution Command

The higan-bundle script executes in the foreground, automatically detects whether it is running on Void Linux (using xbps-install / hein) or Arch Linux (using pacman), and wires any required service daemons: 

sudo higan-bundle --dev --gamer
